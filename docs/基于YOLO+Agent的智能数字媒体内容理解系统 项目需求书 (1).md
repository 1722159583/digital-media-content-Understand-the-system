**一、项目概述**

**1.1 项目背景**

针对游戏录屏、短视频等数字媒体素材人工审核、标注效率低、标准不统一的痛点，结合计算机视觉与大模型 Agent 技术，搭建自动化内容理解系统，实现素材智能分析与审核的业务闭环。

**1.2 项目目标**

基于 YOLO 视觉检测与 Agent 编排能力，构建可交互、可运行的智能内容理解系统，完成素材上传、目标检测、智能分析、内容审核、数据留存全流程，满足课程设计基础交付标准。

**1.3 项目范围**

覆盖用户权限、素材处理、视觉检测、Agent 分析、知识库检索、审核管理、基础统计的核心业务闭环，为课程设计必做基础功能。

**二、用户角色与权限**

**2.1 角色划分**

**普通用户**：素材上传、查看检测分析结果、管理个人素材与历史记录

**审核管理员**：内容复核、审核状态流转、查看全量素材与统计数据

**系统管理员**：用户账号管理、模型配置、知识库维护、日志管理

**2.2 权限要求**

实现完整的用户注册、登录、退出功能

所有业务接口需做身份权限校验，不同角色仅可访问对应功能

禁止越权访问他人素材与后台管理功能

**三、核心业务流程**

**3.1 正常主流程**

1用户登录系统，进入功能页面

2上传图片 / 视频素材，系统完成格式校验与预处理

3视频通过 OpenCV 采样提取关键帧，图片直接进入检测环节

4YOLO 模型完成目标检测，输出目标类别、置信度与可视化标注结果

5Agent 读取检测结果，调用知识库匹配规则，生成内容摘要、标签与审核建议

6系统留存全量数据，更新任务处理状态

7用户 / 审核员查看结果，可人工调整审核状态

8支持导出分析结果与审核资料

**3.2 异常处理**

系统需覆盖文件格式错误、空文件、模型缺失、推理失败、数据写入异常等场景，给出明确提示并留存异常日志。

**四、功能性需求**

**4.1 用户与权限管理模块**

用户注册：支持账号密码注册，校验账号唯一性

登录 / 退出：实现身份校验与会话管理，登录失效自动跳转登录页

角色权限控制：基于角色分配功能与数据访问权限

个人信息管理：支持修改密码、查看个人操作记录

**4.2 素材上传与管理模块**

素材上传：支持单张 / 批量图片、单视频上传，自动校验文件格式与大小

视频预处理：基于 OpenCV 均匀采样提取关键帧，记录对应时间点

素材列表：支持按时间、审核状态筛选，查看素材基础信息与处理状态

历史记录：支持查看个人历史处理记录，可跳转详情页

素材详情：同步展示原始素材、检测标注结果、Agent 分析结论与审核状态

**4.3 视觉目标检测模块**

目标检测：基于 YOLO 输出目标类别、置信度、检测框坐标，支持结果可视化

自定义检测：训练场景化 YOLO 模型，识别游戏角色、道具等特定目标

视频评分：支持画面变化幅度、运动强度、目标数量三类维度评分

异常适配：兼容模型缺失、推理失败、低置信度等场景，给出错误提示

**4.4 Agent 智能分析模块**

核心能力：搭建 1 个主控 Agent，包含视觉结果解析、知识库检索、报告生成至少 3 个工具节点

内容生成：基于检测结果与知识库规则，自动生成素材摘要、分类标签、审核建议

流程可追溯：支持查看 Agent 调用链路、工具执行日志，保证结果可解释

**4.5 知识库与向量检索模块**

知识库管理：包含数字媒体审核规范、素材分类规则两类内容，支持知识点增删改

向量化处理：基于 Embedding 模型对知识库内容向量化，构建向量索引

RAG 检索：根据检测结果语义检索匹配知识库内容，作为 Agent 分析依据

效果验证：支持查看检索命中的知识点与相似度得分

**4.6 内容审核管理模块**

三态审核：支持通过、待复核、不通过三种审核状态流转

人工复核：审核员可修改自动审核结论，补充审核备注

记录留存：完整记录状态变更的操作人、时间与原因

审核筛选：支持按审核状态、素材类别、处理时间筛选任务

**4.7 统计可视化模块**

基础统计：统计检测类别分布、置信度分布、审核状态占比

图表展示：生成目标数量、置信度分布、视频时间段分析可视化图表

数据导出：支持统计数据导出为 CSV 格式

**4.8 报告导出模块**

单素材导出：支持导出 JSON 格式分析报告、检测证据图片、审核资料包

批量导出：支持批量选中素材导出汇总分析结果

**4.9 系统管理与日志模块**

用户管理：管理员可新增、禁用账号，调整用户角色

模型配置：支持切换检测模型、调整置信度阈值

操作日志：记录用户操作与系统异常，支持问题溯源

任务管理：实时展示处理进度，失败任务支持重试

**五、非功能性需求**

**性能要求**：单张图片全流程处理不超过 10 秒，1 分钟内短视频处理不超过 30 秒，页面接口响应不超过 2 秒

**兼容性要求**：兼容 Chrome、Edge 主流浏览器，支持 JPG/PNG 图片、MP4/AVI 视频格式，接口遵循 RESTful 规范

**稳定性要求**：核心功能可用率不低于 95%，所有异常均有友好提示，关键操作留存日志

**易用性要求**：操作逻辑清晰，处理进度可视化，错误提示通俗易懂

**六、数据需求**

**6.1 数据来源**

测试素材：公开游戏录屏、短视频素材，人工整理标注

知识库数据：人工整理的内容审核规范、素材分类规则

业务数据：用户信息、素材元数据、检测结果、审核记录、操作日志

**6.2 数据规模**

整理不少于 30 条素材元数据，记录来源、类别、标签与处理结果

测试集包含不少于 20 张图片、3 个视频样例，覆盖至少 5 个成功案例、3 个失败 / 低置信度案例

**6.3 核心存储内容**

系统需存储用户表、素材表、检测结果表、分析结果表、审核记录表、知识库表、系统日志表七类核心数据。

**八、验收与交付标准**

**8.1 功能验收标准**

业务闭环完整：可完成素材上传到结果导出的全流程操作，无核心功能缺失

Agent 功能有效：可正常调用至少 3 个工具，输出结果与检测、知识库内容匹配，调用链路可追溯

核心功能可用：YOLO 检测与知识库检索可输出有效结果，成功率符合预期

工程稳定：注册登录、权限校验、接口响应、异常处理正常，无致命 bug

测试完整：具备正常流程、失败流程、异常场景的测试用例与结果记录

完整项目源代码、依赖文件、启动说明，可直接运行 Demo

答辩 PPT、项目全程运行录屏

项目进度日报、Git 提交记录（总提交不少于 25 次，每人至少 5 次有效提交）
