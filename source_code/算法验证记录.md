## 已实现能力

- OpenCV 解码图片和视频，拒绝缺失、空文件及不可解码媒体；
- YOLO 输出统一的 `penta_kill`、置信度及 `[x1,y1,x2,y2]` 检测框；
- 视频逐帧输出帧号和时间戳，保存带框的关键证据帧；
- 使用帧差计算画面变化、稠密光流计算运动强度，并计算目标数量得分；
- 使用 IoU 关联生成目标 ID 和随时间变化的框中心轨迹；
- 支持置信度、采样间隔、跟踪、关键帧开关和项目内自定义权重；
- 无检测结果时返回低置信度/无检测状态和人工复核提示。

## 模型限制

虽然权重内部含三个类别名称，但当前数据并非有效三分类数据：五杀横幅主要使用
原始 class 1 标注，验证集仅有 5 个该类目标，三个数据划分中均没有 `kill_feed`
目标。服务因此将原始 class 0/1 统一输出为 `penta_kill`，并过滤 class 2。

训练日志最后一轮的 Precision 0.9886、Recall 1.0、mAP50 0.995 和
mAP50-95 0.7835 仅可作为该小规模、单一有效类别验证集的训练记录，不代表三分类
泛化性能。正式验收前应扩充跨视频五杀正样本、易混淆负样本，并至少准备 20 张
图片或 3 个视频，其中包含成功、失败和低置信度案例。
